# Security Policy

## Reporting Security Issues

Aurora File Manager is an open-source cross-platform project for **Android**, **iOS**, and **Windows 11 (x86_64 / ARM64)** that takes security and user privacy seriously.

If you discover a potential security issue or vulnerability on Android, iOS, or Windows 11, please report it responsibly by opening a private disclosure or submitting an issue on the GitHub repository:

- **GitHub Issues**: [https://github.com/Computer-genius1/AuroraFileManager/issues](https://github.com/Computer-genius1/AuroraFileManager/issues)

Thank you for helping keep Aurora File Manager secure!
