# Security Policy

## Reporting Security Issues

Aurora File Manager is an open-source project that takes security and user privacy seriously.

If you discover a potential security issue or vulnerability, please report it responsibly by opening a private disclosure or submitting an issue on the GitHub repository:

- **GitHub Issues**: [https://github.com/Computer-genius1/AuroraFileManager/issues](https://github.com/Computer-genius1/AuroraFileManager/issues)

Thank you for helping keep Aurora File Manager secure!
