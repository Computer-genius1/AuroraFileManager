# Contributing to Aurora File Manager

Thank you for your interest in contributing to Aurora File Manager! We welcome pull requests, bug reports, feature suggestions, and localization contributions.

## How to Contribute

### 1. Reporting Bugs
- Open an Issue on GitHub: [Issues Page](https://github.com/Computer-genius1/AuroraFileManager/issues)
- Provide device details (Android version, device model) and steps to reproduce the issue.

### 2. Feature Requests
- Open an Issue tagged as `enhancement`.
- Describe the feature and why it would benefit users.

### 3. Submitting Pull Requests
1. Fork the repository on GitHub.
2. Create a feature branch (`git checkout -b feature/my-feature`).
3. Ensure code formatting aligns with standard Kotlin conventions and builds cleanly:
   ```bash
   ./gradlew testDebugUnitTest
   ./gradlew assembleDebug
   ```
4. Commit your changes and open a Pull Request against the `main` branch.
