# Aurora File Manager

**A free Android file manager with root-level file access.**

Aurora File Manager is an Android application that gives users direct access to files stored on their device, including files that require elevated permissions. It is distributed as a free public release on GitHub and is designed to provide a simple, capable file-management experience with clear safety checks.

## Features

- **Broad file access:** Browse files across the device, including files accessible through root-level permissions.
- **File management:** Create, move, copy, rename, and organize files using the features currently supported by Aurora.
- **Root-level access:** Access a wider range of device files when the required permissions are granted and supported by the system.
- **Authorization safeguards:** Root-level access requires users to approve the access through the supported system or root-management mechanism before use.
- **Deletion safety warning:** Aurora warns users about the potential risks of deleting root-level system files and requires confirmation before dangerous actions proceed.
- **Open source distribution:** Download Aurora from GitHub and help improve the project by testing the app and reporting issues.

## Root-Level Access and Safety

Aurora File Manager provides root-level file access for users who need to work with files beyond the scope of a standard Android file manager.

**Root-level access requires explicit authorization before it can be used.** Users must grant the necessary permission through the supported settings or root-management mechanism. This ensures that elevated access is only enabled when the user intentionally approves it.

Root access is a powerful capability. Deleting critical Android system files can cause serious problems, including system instability, loss of functionality, or an inability to boot the device.

For this reason, Aurora displays a warning before potentially dangerous root-level file deletion. Users must confirm that they understand the risks before proceeding with actions that could affect system files.

Please use caution when interacting with system files. Only delete files when you understand their purpose and the consequences of removing them. Authorization prompts and warnings are there to reduce risk, but they cannot prevent every mistake.
