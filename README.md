# Aurora File Manager

**A free Android file manager with root-level file access.**

Aurora File Manager is an Android application designed to give users broad access to files stored on their devices. Available as a free beta on GitHub, Aurora aims to provide a straightforward file management experience while allowing users to explore files that may not ordinarily be accessible through a standard file manager.

## Features

- **Broad file access:** Browse files across the device, including files accessible through root-level permissions.
- **File management:** Manage files using the file management features currently supported by Aurora.
- **Root-level access:** Access a wider range of device files, subject to the necessary permissions and implemented restrictions.
- **Additional authorization safeguard:** Root-level access requires users to grant the necessary authorization through the supported settings or root-management mechanism before using this feature.
- **Deletion safety warning:** Aurora warns users about the potential dangers of deleting root-level system files and requires an explicit acknowledgment before proceeding with potentially dangerous deletions.
- **Free beta availability:** Download Aurora from GitHub and help improve the project by testing the application and reporting bugs.

## Root-Level Access and Safety

Aurora File Manager provides root-level file access for users who need to browse files beyond the usual scope of a standard Android file manager.

**Root-level access requires additional authorization before the feature can be used.** Users must grant the necessary permission through the supported settings or root-management mechanism. This additional step is intended to provide another safeguard and help ensure that users deliberately enable access to sensitive files.

Root access is a powerful capability. Deleting critical Android system files can cause serious problems, including system instability, loss of functionality, or an inability to boot the device.

For this reason, Aurora displays a warning before potentially dangerous root-level file deletion. Users must check a confirmation box acknowledging that deleting certain files can cause serious device damage and that they accept responsibility for proceeding.

Please exercise extreme caution when interacting with system files. Only delete files when you understand their purpose and the potential consequences. Authorization prompts and warnings can reduce risk, but they cannot guarantee that every operation is safe.

## Known Issues

Aurora File Manager is currently in beta. The following issues are known at this time:

- **File viewing limitation:** Files can be displayed in the file browser, but viewing their contents is not currently supported.
- **Android 17 incompatibility:** Aurora File Manager is not currently compatible with Android 17.

These are the currently identified issues. Additional bugs or compatibility problems may be discovered during beta testing.
