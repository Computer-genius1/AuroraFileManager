# Aurora File Manager

**A free Android file manager with root-level file access.**

Aurora File Manager lets you browse and manage files on your Android device, including protected system files through root-level access. Root access is powerful and should be used with care: deleting or changing the wrong files can cause serious system damage, make your device unstable, or prevent it from booting.

## Features

- **Browse device files:** Explore files across your device, including protected files available through root-level access.
- **File management:** Create, move, copy, rename, and organize files using the features supported by Aurora.
- **Root-level file access:** Access protected files and directories after granting authorization through the supported system or root-management mechanism.
- **Deletion safety warning:** Aurora warns users about the risks of deleting root-level system files and requires confirmation before dangerous deletions.
- **Free public release:** Download Aurora from GitHub Releases and report bugs or share feedback through GitHub Issues.

## Root Access and Critical Safety Warning

Aurora provides **root-level access to files that ordinary Android file managers may not be able to access**. This may include files that are essential to Android or your device manufacturer. Root access requires explicit authorization through the supported settings or root-management mechanism.

> **Warning: Be extremely careful when deleting or changing files with root access. Removing or modifying the wrong system file can cause serious damage, data loss, system instability, or leave your device unable to start. Do not delete a file unless you know what it does and are certain it is safe to remove. Keep a backup of important data.**

Aurora displays a warning and requires confirmation before potentially dangerous root-level deletions. These safeguards cannot prevent every mistake or guarantee that a deletion is safe. Carefully check the file and its location before confirming any action.
